# 数字人健康广告审查

面向数字人健康广告的审查服务：登记素材生成来源、人物身份授权、商品类别、脚本版本、
风险词命中、AI 标识、审核意见、投放渠道与实际获利方，按药品/医疗器械/保健食品等类别
套用不同禁限规则；支持改版重审、冲突挂起、队列分权、证据分级、处置申诉、整改时限
跨重启推进，并能还原一条广告从素材到责任主体与处置结果的完整链路。

当前版本为纯标准库 Python 3.11 实现，数据均为演示用虚构内容。

## 模块

| 模块 | 职责 |
| --- | --- |
| `model.py` | 领域模型：主体、身份授权、数字人素材、AI 标识、商品、脚本版本、风险命中、审核意见、投放快照、证据、任务、冲突、事件、案件 |
| `rules.py` | 版本化规则集 `rb-2026.09`：分类别禁限词条（断根/代言/疾病治疗/绝对化用语/虚构体验）、AI 标识、身份授权、文号与警示语结构检查 |
| `access.py` | 队列分权、利益关联回避（商品方不能批准自己的广告）、证据分级（法务见原件，审核员见摘要） |
| `service.py` | 审查工作流：提交幂等、改版重审、冲突挂起/解除、审核、巡查立案、投放拦截、下架/通知/整改/申诉、时限推进 |
| `store.py` | JSON 快照持久化与恢复（截止时间是绝对时间，不依赖进程存活） |
| `reports.py` | `chain()` 结构化链路与 `render_text()` 可读报告 |
| `cli.py` | 端到端演示：白大褂药膏挂起案、保健食品改版申诉案 |

## 关键规则

- **脚本版本**：内容 SHA-256 哈希变化即新版本，必须重新审核；审核意见记录规则版本与审核人。
- **幂等**：相同 `素材 + 脚本哈希 + 发布账号` 的重复提交直接沿用原结论（REUSE）并指向原审核。
- **冲突挂起**：获利方缺失/未登记、文号与类别不匹配、注册人与链接方未登记、
  同一素材换账号再发（含下架后复活）——一律挂起调查，未决冲突不得通过。
- **分类别禁限**：
  - 药品/医疗器械：禁功效保证、治愈率、绝对化用语；禁医务人员形象代言（授权也不行）；需批准文号。
  - 保健食品：禁疾病治疗/替代药物；批件功能声称限缩；须含“本品不能代替药物”；需食健字号。
  - 普通商品/食品（含消字号）：禁医疗用语（“断根”等）。
  - 全类别：AI 内容须显著标识 + 隐式水印；白大褂须有效身份授权；绝对化用语禁用；
    虚构体验需凭证，限制性声称需证明文件。
- **处置**：在投版本被驳回或被下架时生成下架、通知、整改（24h 绝对时限）任务；
  逾期由 `advance_deadlines()` 系统强制执行下架；申诉成立可撤销处置并恢复在投。
- **分权**：运营者只能处理本队列、分配给自己的任务；审核同样适用回避。

## 演示

```bash
python3 -m src.synthetic_ad_review.cli
```

演示覆盖：无标识白大褂视频宣称断根 → 获利方穿透挂起 → 驳回在投版本 → 下架/通知/整改
→ 换账号再发拦截 → 快照落盘 → 模拟停机 25 小时恢复后整改逾期系统强制下架；
以及保健食品 v1 驳回 → v2 改版重审 → 利益回避/凭证拦截 → 投放 → 申诉成立恢复
→ 重复提交沿用原结论。
