# 数字人健康广告审查

面向平台合规团队的数字人健康广告审查领域服务。围绕「白大褂数字人宣称药膏断根、
脚本/商品链接/投放账户分属不同公司、无 AI 生成标识」这一真实场景建模，实现从素材
登记、分类别规则审核、脚本版本管理、投放后处置到申诉结案的完整责任链。数据均为
演示用虚构内容。

## 能力一览

- **登记九要素**：素材生成来源（制作机构、生成工具）、人物身份与肖像授权、
  商品类别与批准文号、脚本版本、风险词命中、AI 生成标识、审核意见、投放渠道与
  账户控制方、实际获利方。
- **分类别禁限规则**（版本化规则包 `rules-2026.09`，结论固定当时版本）：
  - 全类别：断根/根治/治愈率等功效保证（阻断）、绝对化用语（警告）；
  - 药品、医疗器械：禁止任何代言人推荐证明，医务人员形象直接阻断；
  - 保健食品/普通食品/化妆品：禁止疾病治疗表述；
  - 保健食品：禁止声称替代/辅助药物，要求「本品不能代替药物」提示语；
  - 数字人视频缺失生成合成标识：阻断；
  - 身份授权缺失、过期、范围不符：阻断；虚构医务人员身份：阻断。
- **脚本版本**：脚本内容哈希固化为不可变版本，任何修改产生新版本并强制重审；
  投放记录固定当时投放的版本编号，事后修改不影响追溯；内容未变则沿用版本。
- **幂等提交**：以「素材+脚本哈希+商品+渠道+投放账户」为幂等键，重复提交直接
  沿用原案件与原结论，不重复审核。
- **冲突挂起**：商品链接控制方与备案主体不一致、实际获利方与广告主/备案主体均
  不同、同一素材换主体或账户再次发布时，案件自动挂起调查；调查放行或驳回后才
  能继续。
- **审核权限**：
  - 商品方及任何责任关联方（广告主、获利方、制作方、备案/链接主体、脚本撰写方）
    的审核员一律回避，不能裁决自己的广告；
  - 平台运营者只能看到和完成分配给自己队列（按渠道划分）的处置任务；
  - 法务可查看证据原件，普通审核员/运营者只能看到素材摘要，原件引用被遮蔽。
- **处置任务**：已投放广告被驳回或撤销时，自动生成下架（24h）、通知（24h）、
  限期整改（72h）任务，按渠道进入运营队列；逾期标记 overdue，超过 24h 宽限
  自动升级到 escalation 队列。
- **恢复后推进**：状态以 JSON 快照原子落盘；截止时间是绝对时间，停机时间计入
  整改时限，服务重启即重新扫描，长停机可一次跨越逾期直接升级。
- **申诉**：仅责任主体可对撤销处置申诉；申诉成立撤销未执行任务并恢复暂停投放，
  申诉驳回维持处置；裁决人同样适用利益回避。
- **全链路还原**：`trace(case_id)` 一次还原责任主体、素材与身份、商品、全部脚本
  版本、历次审核结论及命中规则、投放记录、处置任务、申诉与按时间排序的事件时间线。

## 代码结构

```
src/synthetic_ad_review/
  models.py   # 领域模型、枚举与 JSON 序列化
  rules.py    # 分类别禁限规则与风险命中（版本化规则包）
  store.py    # JSON 快照持久化（原子写入）
  service.py  # 审查服务：提交、冲突、审核、投放、处置、申诉、时限、链路还原
  demo.py     # 端到端演示
  context.py  # 领域资料读取与校验（初始骨架，保留）
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

32 个测试覆盖规则引擎各品类、幂等与换号检测、冲突挂起、利益回避、版本重审、
队列隔离、撤销处置、停机恢复后的逾期与升级、申诉成立/驳回、证据分级与链路还原。

## 编译

```bash
python3 -m compileall -q src tests
```

## 端到端演示

```bash
python3 -m src.synthetic_ad_review.demo
```

演示主线：登记四家相互独立的公司 → 提交即因主体冲突挂起 → 调查放行后命中
「断根/永不复发/医务人员代言药品/无 AI 标识」被驳回 → 脚本修改强制重审、
商品方自批被拦截、独立审核员通过合规版本 → 投放后巡检撤销并生成下架/通知/
整改任务 → 停机 26 小时恢复后任务自动逾期 → 队列运营者完成处置、案件结案 →
法务视角还原完整证据链（普通审核员只见摘要）。
